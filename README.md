# shortest-paths-turkish-cities
A Java-based application that calculates the shortest path between cities in Turkey using graph algorithms.

The system models cities as nodes and distances as weighted edges, then applies Dijkstra’s algorithm to find the most efficient route between two locations.

Designed to simulate real-world navigation and routing problems.
- Graph-based modeling of Turkish cities
- Shortest path calculation using Dijkstra’s Algorithm
- Efficient handling of weighted graphs
- Console-based user interaction
  
- Tech Stack: Java, Graph Data Structures, Dijkstra Algorithm
